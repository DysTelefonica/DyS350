# Project documentation references

- For operational questions about JSON loading, Preventa roles, notifications, signatures, document libraries, permissions or provisioning, start with [docs/README.md](docs/README.md) and the [operational manual](docs/manuals/guia-consulta-operativa.md). Preserve the manual's read-only diagnostic scope unless a change is explicitly requested.
- The team's ongoing documentation location is SharePoint DOC IT, linked from the documentation hub. Consult it for current revisions when authorized corporate access is available; otherwise state that freshness could not be checked. Local snapshots are not automatically synchronized.
- For implementation questions, inspect the relevant source code. The manual is an operational reference, not proof of current code or deployed behavior. Flag disagreements between documentation, code and live evidence explicitly.
- When updating a reference, update its original snapshot, searchable transcription, provenance and hub entry together. Follow the [reference maintenance process](docs/README.md#keeping-references-current), and never persist credentials or tokens.
