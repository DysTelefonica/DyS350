## What was attempted and did not reach the release

- **The state of the guard in a column of the staging list** (`ClaveGeneracionJSON`). It was
  designed, measured and abandoned: the definition of the operations of the connection of the flows
  is a copy made before the column existed, and the platform refuses the parameter of the write
  ("The API operation does not contain a definition for parameter 'item/ClaveGeneracionJSON'"). The
  column is still in the staging list of DEV/CERT and it is empty; it was **not** created in PROD.
- **Reading the file of the state by three other forms**: the complete URL in `decodedurl` (400,
  the server relative path cannot have the host), `RootFolder/Files/<nombre>/$value` without the
  parenthesis (404) and the listing of the library (the name of a file is not in any field that the
  connector returns). The form that works is `RootFolder/Files('<nombre>')`.
- **A decision with the comparison inside the condition of the `if`**. The platform does not
  refuse it when the flow is published: it refuses it when the expression is evaluated ("The
  template language function 'if' expects three parameter ... The function was invoked with '1'
  parameter(s)"). The comparison is now in its own action and the tests count the arguments of
  every function of the guard.
- **Promoting to PROD by copying the definition of DEV/CERT**. It was discarded before publishing
  anything: the copy would have taken away the authentication of the actions, the polling of the
  trigger (one minute in PROD, five in DEV/CERT) and the check of the limit of the snapshots.
